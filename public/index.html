How TinyFish Endpoints Are Used (200 Pts Tier)

1. TinyFish Search API (api.search.tinyfish.ai)

Dynamically searches live ATS boards (Greenhouse, Lever, Ashby) with tailored search operators for your exact job title and location. Discovers new postings live without hardcoded lists.

2. TinyFish Fetch API (api.fetch.tinyfish.ai)

Batch renders modern JavaScript SPAs using TinyFish's managed Chromium fleet, bypassing client-side hydration hurdles and extracting clean markdown job descriptions and qualifications.

3. TinyFish Agent API (agent.tinyfish.ai/v1/automation/run)

Autonomous "AI That Clicks" for interactive corporate career boards (like Stripe, Zomato, Blinkit) — navigating dropdowns and extracting structured data conforming to a JSON schema.
